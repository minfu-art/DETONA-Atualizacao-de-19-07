# Manual de importação

1. Reúna somente dados oficiais.
2. Monte manifesto, currículo, lotes e assets.
3. Valide localmente IDs, pais, subtópicos, gabaritos e imagens.
4. Chame `validate_course_bundle`.
5. Mostre contagens, hashes, conflitos e avisos.
6. Exija a frase exata de confirmação.
7. Chame `apply_course_bundle` uma única vez.
8. Consulte `get_course_operation`.
9. Confira o curso no Painel Central.
10. A revisão, snapshot, pacote e publicação continuam manuais no Painel.
