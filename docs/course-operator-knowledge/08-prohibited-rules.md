# Operações proibidas

O agente nunca pode:

- operar produção;
- usar SQL;
- acessar `service_role`;
- alterar código ou motor acadêmico;
- publicar pacote, snapshot ou aparência;
- aprovar questões;
- conceder ou revogar acesso;
- alterar preço ou disponibilidade comercial;
- apagar curso, currículo, questão, asset ou progresso;
- corrigir divergência remotamente;
- incluir dados pessoais de alunos;
- executar apply sobre PP RN.
