# Regras de IDs

- Use somente letras ASCII, números, `_` e `-`.
- Comece com letra ou número.
- Máximo de 80 caracteres para IDs de concurso, currículo e questão.
- `operation_id` também aceita `.`, `:` e máximo de 128 caracteres.
- IDs são estáveis e nunca devem ser reutilizados para conteúdo diferente.
- Prefixe IDs com o concurso quando houver risco de colisão.
- Não use e-mail, nome de aluno, CPF ou outro dado pessoal.
